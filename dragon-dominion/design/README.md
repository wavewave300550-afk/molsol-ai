# Design intake (not shipped)

One folder per approved creature: `design/creatures/<name>/` with `spec.md`, `reference/`
(approved concept art, all angles) and `source/` (Blockbench `.bbmodel`, layered textures,
audio masters). Nothing in `design/` is packaged. See
[../docs/ADDING_A_CREATURE.md](../docs/ADDING_A_CREATURE.md).
