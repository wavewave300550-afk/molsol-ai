# RIFT RIOT — ศึกซิ่งป่วนจักรวาล

เกมแข่งความเร็ว 3D แนว arcade บนเว็บ เล่นได้ทั้งบน iPhone (สัมผัส) และคอมพิวเตอร์ (คีย์บอร์ด)
สร้างด้วย **three.js 0.187** + **Vite** โดยไม่มีไฟล์โมเดล รูป หรือเสียงจากภายนอก:
โมเดลตัวละครทั้งหมดประกอบจากรูปทรงในโค้ด (toon shading), เสียงทั้งหมดสังเคราะห์สดด้วย WebAudio

## ในเวอร์ชันนี้มีอะไร

- ผู้เข้าแข่งขัน **6 ตัว** ทุกตัวฟรีและเลือกได้ทันที มีสกิลเดียวต่อตัว
  | # | ตัวละคร | การเคลื่อนที่ (แสดงผล) | สกิล |
  |---|---|---|---|
  | 001 | ลุงบุญส่ง | ยืนโยกคันโยกรถรางโยกมือ ยิ่งเร็วยิ่งโยกถี่ | **RAIL MAKER** วางรางชั่วคราว 4 วิ ลอยข้ามช่องว่าง/พื้นลื่นได้ |
  | 002 | BABY HAVOC | นั่งในรถเข็นเทอร์โบ จิ้มรีโมท ผ้าใบสะบัด | **HELLISH TANTRUM** เตรียม 0.2 วิ แล้วคลื่นผลักรอบตัวครั้งเดียว |
  | 003 | CELESTINE | เดินเขย่งในลูกบอลใส ลูกบอลกลิ้ง ตัวยังตั้งตรง | **PIROUETTE** หมุนตัว เร่งเป็น 1.25× นาน 3 วิ |
  | 004 | GRANNY CRACKLEBONE | วิ่งท่าสะพานโค้งด้วยมือและเท้า หน้ากลับหัวยิ้มหาคนข้างหลัง | **SPINE SLINGSHOT** ย่อ 0.25 วิ แล้วดีดตัวเป็นวิถีโค้ง ~1.2 วิ |
  | 005 | LOVE NEVER SINKS | คู่รักยืนท่าหัวเรือนิ่งตลอด บนแมนาทีที่นอนบนแท่นล้อ | **ETERNAL LOVE** แท่นล้อปล่อยฟองหัวใจ ทิ้งพื้นลื่น 4 วิ (แต่ละแผ่นอยู่ 3 วิ) |
  | 006 | UNCLE GATOR | ห้องน้ำลอยต่ำ ประตูเปิดหันหากล้อง ลุงอุ้มแอลลิเกเตอร์ | **FLORIDA HURRICANE** ห้องน้ำหมุนเป็นพายุ 4 วิ ผลักคนใกล้ตัว (เป้าเดิมไม่ถี่กว่า 0.9 วิ) |
- สนาม **RIFT JUNCTION — ชุมทางมิติหลุด** วงรอบเดียว ~1.6 กม. 4 ช่วง: ลานชุมทาง → ถนนงานเลี้ยงน้ำชายักษ์ (ถ้วยชาเลื่อนข้ามถนนตามจังหวะ มีป้ายเตือนและลายพื้นบอกเขต) → สะพานมิติแตก (ขอบเปิด + ทางลัดตรงที่มีช่วงสะพานเปิด–ปิด ไฟเขียว/เหลืองกะพริบ/แดง) → โค้งตัวเอสและทางตรงกลับเส้นชัย
- แข่ง 3 รอบ ผู้เล่น 1 + AI 5 (AI ใช้ตัวที่เหลือครบทุกตัว) หนึ่งการแข่งขันประมาณ **2 นาที 25 วิ**
- เมนูครบ: หน้าเริ่ม → เลือกตัวละคร (โมเดล 3D จริงหมุนบนแท่น + ภาพย่อที่เรนเดอร์จากโมเดล) → นับถอยหลัง → แข่ง → ผลการแข่งขันจริง → แข่งใหม่ / กลับไปเลือกตัวละคร
- พักเกม (หยุดเวลา AI สกิลและเอฟเฟกต์พร้อมกัน), พักอัตโนมัติเมื่อสลับแอป, ปรับเสียง/ปิดเสียง, ปรับคุณภาพภาพ

## วิธีเล่น

**iPhone / มือถือ** — รถเร่งเองอัตโนมัติ
- นิ้วซ้าย: แป้นเลี้ยว (ลากซ้าย–ขวา)
- นิ้วขวา: ปุ่ม **ดริฟต์** (กดค้าง) และปุ่ม **สกิล** (วงแหวนรอบปุ่ม = เวลาทำงาน/คูลดาวน์)
- ปุ่ม **เบรก** แยกเป็นปุ่มเล็กอยู่ห่างจากดริฟต์ กดค้างเพื่อเบรก/ถอย
- ปุ่ม **II** มุมขวาบน = พักเกม
- แนะนำให้ถือแนวนอน (แนวตั้งก็เล่นได้)

**คีย์บอร์ด** — W/↑ เร่ง, S/↓ เบรก, A D/← → เลี้ยว, Space ดริฟต์, E สกิล, Esc พักเกม

ดริฟต์ค้างต่อเนื่อง ~0.9 วิ (ต้องไถลจริงที่ความเร็วพอ) แถบใต้มาตรวัดจะเต็มเป็นสีทอง ปล่อยแล้วได้แรงส่ง 0.5 วิ ไม่สะสมซ้อน กดดริฟต์ถี่ ๆ ไม่ได้แรงส่ง

## รันและเปิดบน iPhone

ต้องมี Node.js 18+ (ทดสอบบน Node 22)

```bash
cd rift-riot
npm install
npm run dev          # เปิด http://localhost:5173 และพิมพ์ Network URL ให้ด้วย
```

เปิดบน iPhone: ให้ iPhone กับคอมพิวเตอร์อยู่ Wi-Fi เดียวกัน แล้วเปิด Safari ไปที่ **Network URL** ที่ `npm run dev` แสดง (เช่น `http://192.168.1.20:5173`)
(เลือก “แชร์ → เพิ่มไปยังหน้าจอโฮม” เพื่อเล่นเต็มจอได้)

ไฟล์สำหรับใช้งานจริง:

```bash
npm run build        # ได้ไฟล์เดียว dist/index.html (~745 KB, gzip ~200 KB) ไม่เรียกทรัพยากรภายนอก
npm run preview      # เสิร์ฟ dist/ ที่พอร์ต 4173 (เปิดจาก iPhone ผ่าน Network URL ได้เหมือนกัน)
```

`dist/index.html` วางบน static hosting ใดก็ได้ (โปรเจกต์นี้ไม่ได้อัปโหลดขึ้นบริการภายนอกให้)

## การทดสอบ

```bash
npm test             # กติกาเกม 19 ข้อ (headless, ไม่ต้องใช้เบราว์เซอร์)
npm run balance      # แข่ง AI ล้วน 20 รอบ แสดงอันดับเฉลี่ย เวลา การใช้สกิล การตก
npm run dev & npm run smoke   # end-to-end ใน Chromium ขนาดจอมือถือ + touch (ต้องมี Playwright)
```

`npm test` ครอบคลุม: เลือกตัว/AI ครบ 6, สกิลไม่ซ้ำกัน, ห้ามใช้สกิลก่อน GO และพร้อมใช้ทันทีตอนเริ่ม, เงื่อนไขไม่ครบไม่เสียคูลดาวน์, คูลดาวน์/ระยะเวลาไม่ขึ้นกับ FPS (20/30/60/144), นับรอบปกติ, ทางลัดนับรอบได้, ย้อนเส้นชัยหรือตัดข้ามสนามไม่ได้รอบเพิ่ม, ตกแล้วกลับจุดปลอดภัยด้านหลังโดยไม่คืนคูลดาวน์, คลื่นร้องไห้โดนเป้าเดียวครั้งเดียว และไม่โดนเป้าที่อยู่ต่างระดับ, พายุผลักเป้าเดิมไม่ถี่กว่า 0.9 วิ, เพดานแรงผลักรวม, พื้นลื่นมีผลกับห้องน้ำลอยต่ำแต่ไม่โดนคนกระโดด/รถบนราง/เจ้าของ, พื้นลื่นหมดอายุและไม่สะสม, รางสลายหมด, ตอนสะพานทางลัดปิด รางและการกระโดดข้ามช่องว่างได้ส่วนตัวอื่นตก, ระยะลอยตัวของคุณยาย, แรงส่งดริฟต์, และแข่ง AI จนจบด้วยอันดับที่ล็อกตามลำดับเข้าเส้นชัยจริง

`npm run smoke` ตรวจ: flow ทุกหน้าจอ, เลือกได้ครบ 6, ภาพย่อ 3D, สกิลกดไม่ได้ก่อน GO, แตะสองนิ้ว (เลี้ยว + ดริฟต์) พร้อมกัน, หน้าเว็บไม่เลื่อน/ซูม, พักเกมหยุดทุกอย่าง, สลับแอปแล้วพักอัตโนมัติ, หน้าผลแสดงเวลาจริง, แข่งซ้ำ 3 รอบไม่มี geometry/texture/object รั่ว, คีย์บอร์ด และไม่มี error

## โครงสร้าง

```
src/data/balance.js     ★ ค่าบาลานซ์ทั้งหมด (ความเร็ว เร่ง เลี้ยว ดริฟต์ คูลดาวน์ ระยะเวลา รัศมี แรงผลัก พื้นลื่น การกลับสนาม AI กล้อง)
src/data/racers.js      ★ ข้อมูลผู้เข้าแข่งขัน + ตัวคูณสเตตัสรายตัว
src/sim/                ระบบเกมล้วน (ไม่มีการเรนเดอร์ รันใน Node ได้)
  track.js, trackData.js  เรขาคณิตสนาม ทางลัด checkpoint ถ้วยชา สะพานเปิด–ปิด
  racer.js                ตัวควบคุมการเคลื่อนที่ร่วม (ทุกตัวใช้ฟังก์ชันเดียวกัน)
  skills.js               สกิลทั้ง 6 + กติกากลางการใช้สกิล
  race.js                 สถานะการแข่ง กำแพง พื้น การตก การชน แรงผลัก พื้นลื่น checkpoint อันดับ fixed-step
  ai.js                   AI (ใช้อินพุตเดียวกับผู้เล่น ไม่วาร์ป ไม่ rubber band)
src/render/             การแสดงผล (อ่านสถานะเกมอย่างเดียว)
  models/*.js             โมเดล + แอนิเมชันของแต่ละตัว
  trackView.js, effects.js, view.js (กล้อง)
src/ui/                 HUD อินพุต สัมผัส/คีย์บอร์ด CSS
src/audio/audio.js      เสียงสังเคราะห์ทั้งหมด
```

เพิ่มผู้เข้าแข่งขันใหม่ = เพิ่มรายการใน `racers.js` + โมเดลใน `render/models/` (ลงทะเบียนใน `models/index.js`) + สกิลใน `sim/skills.js` + ค่าใน `balance.js` ไม่ต้องแก้ระบบแข่ง

## การตัดสินใจที่บรีฟไม่ได้ระบุ (บันทึกไว้)

- **แบบสนาม**: ทางลัดคือสะพานตรงตัดโค้งรูป D บนช่วงสะพานมิติแตก ประหยัด ~56 ม. มีช่องว่าง 24 ม. ตรงกลางที่ “สะพานเฟส” เปิด 6.5 วิ / ปิด 7.5 วิ (เตือน 1.6 วิ) — ทุกตัวใช้ได้ตอนสะพานเปิด, ลุงบุญส่งใช้รางและคุณยายกระโดดข้ามได้ตอนปิด ถ้าพลาดจะตกและกลับสนามตามปกติ ไม่มี checkpoint กลางทางลัด
- **รางของลุงบุญส่ง** ยกสูงจากพื้น 0.7 ม. จึงผ่านเหนือพื้นลื่นได้ ความสูงตามพื้นสุดท้ายที่รองรับ (ไม่ขึ้นฟ้า) เลี้ยวได้ครึ่งเดียวของปกติ ยังชนกำแพง และรองรับเฉพาะเจ้าของ
- **ห้องน้ำลอย** สูง 0.55 ม. เป็นแค่การแสดงผล ในเชิงเกมถือว่าอยู่บนพื้น (โดนพื้นลื่น ตกจากขอบได้ ชนสิ่งกีดขวาง)
- **ระยะชนร่วม**: ทุกตัวใช้รัศมีชน 1.5 ม. เท่ากัน ประตูห้องน้ำ/แขนคู่รักไม่มี hitbox
- **กติกากันโดนผลักรัว** (กลาง): หลังโดนผลักครั้งหนึ่งจะไม่โดนซ้ำจากแหล่งใดภายใน 0.4 วิ แรงผลักรวมไม่เกิน 17 ม./วิ และค่อย ๆ ลดลง ไม่มีผลกับเป้าที่ห่างแนวตั้งเกิน 2.4 ม.
- **การกลับสนาม**: ตก (ต่ำกว่าพื้น 14 ม.), ติดค้าง 3.2 วิ, หรือออกนอกเขต 95 ม. → รอ 1.1 วิ แล้ววางที่จุดปลอดภัยล่าสุดที่ผ่านจริงถอยหลัง 8 ม. พร้อมกันโดนผลัก 1.4 วิ เวลาแข่งและคูลดาวน์เดินต่อ
- **ชนกำแพง**: ไถลเลียบกำแพงแบบ arcade (หันตามกำแพงเล็กน้อย) แทนการติดค้าง
- **ดริฟต์**: ความเร็วด้านข้างที่หายไปตอนดริฟต์ 80% ถูกแปลงกลับเป็นความเร็วไปข้างหน้า เพื่อให้ดริฟต์เป็นเครื่องมือรักษาความเร็ว
- **หลังผู้เล่นเข้าเส้นชัย** AI แข่งต่ออีกสูงสุด 60 วิ ระหว่างอยู่หน้าผล (ตารางอัปเดตตามจริง) ใครไม่จบแสดง “ไม่จบการแข่งขัน” ไม่มีเวลาปลอม
- **ชื่อไทยของ UNCLE GATOR** ใช้ “ลุงเกเตอร์”

## ข้อจำกัดที่ทราบ

- **ยังไม่ได้ทดสอบบน iPhone จริง** ทดสอบใน Chromium headless (Playwright) ขนาดจอ 844×390 และ 390×844 แบบ touch/isMobile ซึ่งไม่ใช่ Safari/WebKit (เครื่องทดสอบไม่มี WebKit) — โค้ดเลี่ยง API ที่ Safari ไม่รองรับ, ปลดล็อกเสียงจากการแตะปุ่ม, ใช้ safe-area และป้องกันการเลื่อน/ซูม แต่ควรลองบนเครื่องจริง
- **FPS**: ใน headless ที่ใช้ซอฟต์แวร์เรนเดอร์ (SwiftShader ไม่มี GPU) วัดได้ ~12 FPS ซึ่งไม่สะท้อนมือถือจริง ฉากใช้ ~100 draw calls / ~120k สามเหลี่ยม มีโหมดคุณภาพอัตโนมัติที่ลดความละเอียดเมื่อเฟรมช้า ดู FPS จริงได้ด้วย `?fps` ต่อท้าย URL
- iPhone ที่เปิดสวิตช์ปิดเสียง (silent) อาจไม่มีเสียงจาก WebAudio
- โมเดลเป็นรูปทรงประกอบแบบ low-poly การ์ตูน ไม่ใช่โมเดลที่ปั้นและ rig ด้วยโปรแกรม 3D
- พารามิเตอร์ URL สำหรับนักพัฒนา: `?fps` (แสดงประสิทธิภาพ), `?laps=1`, `?autopilot` (AI ขับแทนผู้เล่น ใช้ทดสอบ), `preview.html?m=<id>` (ดูโมเดลเดี่ยว)
