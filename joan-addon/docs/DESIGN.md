# BOSS 001 — Joan of Arc · The Banner of Divine Paths — Design Spec

เอกสารนี้คือ "สัญญา" ที่โค้ดทั้งหมดยึดตาม (ตัวเลขเป็นค่าเริ่มต้นระดับ Normal; ค่าจริงอยู่ใน `src/config.ts`)

## 1. แกนคอนเซปต์: Divine Pathway

**เส้นทาง (Path)** คือวัตถุจริงในสคริปต์ ไม่ใช่ภาพประกอบ มีคุณสมบัติ:

| คุณสมบัติ | ความหมาย |
|---|---|
| `points / cum` | จุดตัวอย่างทุก ~0.5 บล็อก + ความยาวสะสม (arc length) |
| `flow` (+1/−1) | ทิศไหล ย้อนได้ (`reverse`) พร้อมสัญญาณเตือน |
| `speed` | ความเร็วกระแส (บล็อก/tick) |
| `radius`, `band` | ท่อจับ: ระยะแนวราบ + ช่วงความสูง (ถนนพื้นจับต่ำ กระโดดข้ามได้; ถนนเผาไหม้/วงปิดเฟส 2 สูง กระโดดข้ามไม่ได้) |
| `loop` | วงปิด ไหลวนไม่สิ้นสุด |
| `next[]` | ต่อเนื่องไปเส้นอื่นเมื่อสุดทาง (1 เส้น = ต่อ/รวม, หลายเส้น = แยกแขนง) |
| `junctions` | จุดบนเส้นที่ป้อนเข้าแขนงอื่นกลางทาง (ใช้ใน False Salvation) |
| `burning` | เฟส 2: อยู่บนเส้น = ไฟลวก |
| `switching` | เฟส 2: ที่จุดตัด เส้นนี้ "แย่ง" สิ่งที่ไหลผ่านมาจากอีกเส้น |
| `memory` | เส้นที่หมดอายุยังทิ้ง "รอยแผลถนน" ไว้ 40 วินาที ใช้ซ้ำได้ (Martyr's Procession) |
| state | `forming` (เตือน: เส้นทองประ + ลูกศร) → `active` → `fading` → `dead` |

**ฟิสิกส์ต่อ tick:** สิ่งที่อยู่ในท่อจับจะถูกตั้งความเร็ว = tangent × speed + แรงดึงเข้าแนวกลาง
* ผู้เล่น: `applyKnockback` (เกราะ knockback resistance ลดแรงได้จริง)
* ม็อบ: `clearVelocity + applyImpulse`
* กระสุน (ลูกธนู, ตรีศูล, สโนว์บอล, ไข่, เพิร์ล, fireball, wind charge, ยา): หมุนทิศตามเส้นโดยคงความเร็ว → เปลี่ยนวิถีกระสุนได้จริง
* Joan: ขี่เส้นด้วยความเร็วสูง (surf) เคลื่อนที่ตามวิถีผิดธรรมชาติ (โค้งกลางอากาศ, ลูปตีลังกา)

**กติกาที่ผู้เล่นเรียนรู้ได้ (counterplay):** ย่อตัว = ต้านกระแส (ช้าลง 60%, ไม่ถูกดึงเข้ากลาง) · กระโดดข้ามถนนพื้น · ออกด้านข้างของท่อ · ฟาดโหนด (Waystone/ธงผี) เพื่อย้อนหรือทำลายเส้น · ยิงธนู "ไปตามกระแส" ที่ไหลเข้าหา Joan = ทำดาเมจโบนัส (Turned Road)

**ภาษาภาพ (สัญญาณเตือนคงที่ทั้งเกม):**
* เส้นทองประ + ลูกศรวิ่ง = เส้นกำลังก่อตัว (ยังไม่ทำงาน) บอกทิศล่วงหน้า
* สายธารฟ้า-ขาว-ทอง = กระแสทำงาน (เฟส 1 ไม่ทำดาเมจ)
* สายธารส้ม-แดง + ประกายไฟ = ถนนเผาไหม้ (เฟส 2)
* ลูกศรกะพริบแดง-ทอง = กำลังจะย้อนทิศ
* ดอกลิลลี่ทองบนพื้นที่ขยายตัว = จุดกระแทก (ระเบิดเมื่อวาดเสร็จ)
* ลิลลี่กลับหัวสีหม่น = ทางลวง (False Salvation)
* วงแหวนหดตัว = วงปิดกำลังบีบ
* เสียง: chime = เส้นก่อตัว, ระฆังทุ้ม = ท่าหนักกำลังมา, ผ้าสะบัด = ง้างธง, คณะนักร้อง = ultimate/เปลี่ยนเฟส

## 2. การต่อสู้

### Melee (ธงเป็นอาวุธชิ้นเดียว)
| ท่า | ผล | เส้นทางที่เกิด |
|---|---|---|
| Standard Sweep / Back-sweep | โค้ง 140° ระยะ 3.8 | กระแสโค้งสั้นผลักไปตามทิศสะบัด |
| Pole Thrust | แนวตรง 4.5 | กระแสตรงผลักออกจากตัว → ต่อด้วย Surge |
| Standard Plant (ปิดคอมโบ) | วงรัศมี 3 | ซี่ล้อ 6 เส้นไหลออก |
| Banner Wrap (เฟส 2) | คว้าในกรวยแคบ | โยนผู้เล่นลงบนถนนที่ใกล้ที่สุด |

### 7 สกิล + Ultimate
1. **Banner Trail** — ลากธงพุ่งซิกแซก 2–3 ช่วง ทิ้งเส้นทางตามทิศที่พุ่ง (กระแสพาไปหาท่าถัดไป) · เฟส 2: ซิกแซกตัดกันเองบนตัวผู้เล่น → กองไฟที่จุดตัด (Crossroads Judgment)
2. **Pilgrim's Surge** — ขี่เส้นเดิมถ้ามี ไม่งั้นวาด "ถนนโค้งฟ้า" ขึ้นกลางอากาศแล้วพุ่งลงจุดที่เล็งล่วงหน้า กระแทกธง + คลื่นวง (กระโดดหลบได้) · เฟส 2: ลูปตีลังกากลางอากาศ + ต่อ 3 ช่วง (Burning Pilgrimage)
3. **Road of Orléans** — ปักธง ถนน 3 เลนพุ่งผ่านผู้เล่น ไหลออกก่อน → เตือน → **ย้อนทิศ** ดูดกลับเข้าหา Siege Breaker · เฟส 2: เลนกลาง/ข้างไหลสวนกันและสลับเป็นระยะ
4. **False Salvation** — วงปิดล้อมผู้เล่นแล้วหดตัว มีทางออก 3 แขนง (แยกจากวง) 1 ทางเป็น "ทางลวง" ที่วกกลับเข้าวง/ไปหา Joan สังเกตลิลลี่กลับหัว · เฟส 2: วงสูงกระโดดข้ามไม่ได้, เหลือทางจริง 2 ทาง
5. **Convergence of the Standard** — ปักธงผี 3–4 ผืนรอบผู้เล่น แต่ละผืนส่งถนนไหล **รวมกัน** ที่จุดเดียวแล้วฟ้าผ่าแสง · ทำลายธงผีได้ (ฟาด 3 ครั้ง) → ถนนผืนนั้นพลิกย้อนเหวี่ยงออก (ทางหนี) · เฟส 2: จุดรวมคือตัว Joan เอง
6. **Heaven's Detour** — หมุนธงเหนือหัว สร้างวงโคจร 2 วงไขว้รอบตัว **จับกระสุนแล้วเหวี่ยงคืน** ผู้ยิง พร้อมปล่อย Seraph Light ที่บินตามเส้นโค้งอ้อมสิ่งกีดขวาง (เห็นเส้นก่อน) · เฟส 2: เส้นแยกแขนง ลูกแสงแตกเป็น 2
7. **Martyr's Procession** — ปลุกเส้นทางเก่าที่จำไว้ทั้งหมด ให้ "เงาขบวนแห่" (ร่างโปร่งแสงของ Joan) เดินตามรอยเดิม ฟันหนึ่งครั้งก็สลาย · เฟส 2: เงาลุกไฟและจุดตัดกลายเป็นกองไฟ
* **ULT: Road to the Stake** (เฟส 2, HP ≤ 30%) — หลักเพลิงโผล่กลางสนาม ถนนก้นหอย 5 แขนงดูดทุกอย่างเข้าหาหลัก มี **Lily Waystone** ที่ปลายแขนง ฟาดเพื่อ **ย้อนแขนง** (กลายเป็นทางปลอดภัยสีขาว) · กองไฟวิ่งตามแขนงที่ยังไม่ย้อนเป็นระยะ · ถ้าย้อนครบทุกแขนงก่อน 12 วินาที → ถนนไหลเข้าตัว Joan เอง ถูกมัดกับหลักเพลิงของตัวเอง (Martyr's Echo: มึน 6 วินาที รับดาเมจ +50%) · ถ้าไม่ครบ → หลักเพลิงปะทุ ผู้ที่ยืนบนแขนงบริสุทธิ์ปลอดภัย

### เฟส
* **Phase I — The Maiden Standard:** เส้นเรขาคณิตสะอาด (ตรง โค้ง วง) ทิศเดียว ไม่ทำดาเมจ ใช้วางกับดักเป็นระบบ
* **Phase II — The Saint of the Burning Road** (HP 50%): ฉากเปลี่ยนเฟส (คุกเข่า ปักธง ธงลุกไฟ ถนนทุกเส้นเผาไหม้ ท้องฟ้ามืด) แล้วกติกาเปลี่ยนจริง: ถนนเผาไหม้, จุดตัด = กองไฟ, ถนน "กระสับกระส่าย" ย้อนทิศเป็นระยะ, จุดตัดสลับเส้น, ท่าใหม่และคอมโบใหม่, Ultimate

### Combat Intelligence
* สังเกต: ระยะ, ความสูง, line of sight, การง้างธนู/โดนยิง (rangedScore), การตีประชิด, การกระโดดหนีเส้น, อัตราการโดนกระแสจับ, หนีห่าง (kiting), ยืนนิ่ง (turtling), HP ต่ำ, กำลังถูกกระแสพา, จำนวนเส้นในความจำ
* เลือกท่าด้วย utility score + cooldown + ห้ามซ้ำติดกัน + ช่วงพักบังคับหลังท่าใหญ่ 2 ท่า
* คอมโบเชิงเงื่อนไข: Trail→Surge บนเส้นเดิม · Orléans→Plant · Convergence→Surge · False Salvation→Sweep ที่ทางลวง · Detour→Seraph · Procession→กองไฟจุดตัด
* ไม่มีท่าที่หลบไม่ได้โดยไม่มีการเตือน: เตือนขั้นต่ำ 0.9 วิ (เฟส 1) / 0.6 วิ (เฟส 2); Hard ×0.85, Easy ×1.3

## 3. ฉากและองค์ประกอบเพิ่มเติม
* **ฉากเปิดตัว:** ถนนแสงลงมาจากฟ้า Joan ขี่ลงมา ปักธง ยืนขึ้น สะบัดธงคลี่ ชื่อบอสขึ้นจอ วง Processional Ring (ขอบสนาม) ก่อตัว
* **ฉากพ่ายแพ้:** คุกเข่า ไฟดับ ธงกลับเป็นสีขาวบริสุทธิ์ ถนนทุกเส้นกลายเป็นแสงไหลขึ้นฟ้า ร่างสลาย ทิ้งรางวัล
* **กลไกลับ:** ระฆังแห่ง Domrémy (ตีระฆังใกล้สนาม = Joan หยุดฟังเสียงสวรรค์ ครั้งละเฟส) · Turned Road · Unburnt Heart (ชนะหลังจากมัด Joan กับหลักเพลิงของตัวเอง)
* **รางวัล:** Banner of Divine Paths (สร้างถนนพาตัวเอง/ปัดกระสุน), Unburnt Heart (อัญเชิญรอบใหม่), Pilgrim's Standard (ไอเท็มอัญเชิญแบบคราฟต์)
